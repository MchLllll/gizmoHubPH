# GizmoHub PH

Static site. Open with any static server (`npm start`, then http://localhost:8000).

- `index.html`   page content
- `css/styles.css`   all styles, tokens at the top (`:root`)
- `js/main.js`   mobile menu and scroll reveals
- `src/hero.js`   Three.js hero source
- `js/hero.js`   built bundle of `src/hero.js` (run `npm install && npm run build` after editing the source)
